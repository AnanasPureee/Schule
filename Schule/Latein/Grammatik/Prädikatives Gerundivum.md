
# Bildung

- Präsensstamm (+ Sprechvokal) + nd + o-/a- Dekl. Endung + Form von esse
	- discere - disc-e-nd-us

# Übersetzung

- Form von sein + zu + Infinitiv
- Form von müssen + Verb im Inf. Passiv
- Mit Verneinung:
	- form von sein + nicht + zu + Inf.
	- nicht dürfen + Inf. Passiv

# Beispiel

- Homines fugientes (non) servandi sunt.
	- Flüchtende Menschen sind (nicht) zu retten.
	- Flüchtende Menschen müssen gerettet werden.
	- Flüchtende Menschen dürfen nicht gerettet werden.
