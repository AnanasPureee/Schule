

# Wichtige Konjunktionen

## Temporal (Zeit):

| Konjunktion         |          Übersetzung          |
| ------------------- | :---------------------------: |
| cum (m.Konj.)       |     als. nachdem, während     |
| cum (m.Ind.)        | als (plötzlich), immer (wenn) |
| dum                 |       während, solange        |
| postquam            |            nachdem            |
| antequam, priusquam |             bevor             |

## Kausal (Grund):

| Konjunktion   | Übersetzung |
| ------------- | :---------: |
| quod          |    weil     |
| quia          |    weil     |
| cum (m.Konj.) |  da, weil   |
| quoniam       |  weil (ja)  |

## Konditional (Bedingung):

| Konjunktion |    Übersetzung    |
| ----------- | :---------------: |
| si          |    wenn, falls    |
| nisi        | wenn nicht, außer |
| sin         |     wenn aber     |

## Final (Zweck):

| Konjunktion |              Übersetzung              |
| ----------- | :-----------------------------------: |
| ut          |          dass, damit, sodass          |
| ne          | dass nicht, damit nicht, sodass nicht |

## Konzessiv (Einräumung):

| Konjunktion       |      Übersetzung      |
| ----------------- | :-------------------: |
| quamquam          |        obwohl         |
| etsi              |   auch wenn, obwohl   |
| quamvis (m.Konj.) | wie sehr auch, obwohl |
| cum (m. Konj.)    |        obwohl         |
# Relativ Sätze

| Konjunktion         |              Übersetzung               |
| ------------------- | :------------------------------------: |
| [[qui, quae, quod]] | er, die, das; welcher, welche, welches |
| ubi                 |  wo (als Relativsatz mit Ortsangabe)   |
| unde                |                 woher                  |
| quo                 |                 wohin                  |
